# ZOOP 서비스 실행정보

팀에서 확정한 정보만 기록한다.
미정 항목은 담당자 확인 후 업데이트한다.
실제 API 키와 비밀번호는 작성하지 않는다.

## 서비스 현황

| 서비스 | 저장소 | 기술·버전 | 실행 명령 | 포트 | 상태 |
|---|---|---|---|---|---|
| 프론트엔드 | Donbug/Zoop-Frontend | 미정 | 미정 | 미정 | 담당자 확인 필요 |
| 백엔드 | 미생성 | 미정 | 미정 | 미정 | 개발 준비 |
| AI | 최종 저장소 미정 | 미정 | 미정 | 미정 | PoC와 최종 서비스 구분 필요 |
| GraphDB | 해당 없음 | Neo4j, 버전·에디션 미정 | 미정 | 미정 | 사용 예정 |
| 관계형 DB | 해당 없음 | 미정 | 미정 | 미정 | PostgreSQL/MySQL/MariaDB 검토 |

## 각 담당자에게 확인할 정보

- 담당자
- 저장소 주소와 실행 브랜치
- 언어 및 런타임 버전
- 패키지 설치 명령
- 실행 명령
- 사용하는 포트
- 환경변수 이름과 용도
- 연결해야 하는 DB 또는 다른 서비스
- 정상 실행을 확인할 API 주소
- Dockerfile 작성 여부

## 환경변수 작성 규칙

변수 이름과 용도만 공유한다.
실제 값은 별도 방식으로 전달한다.
프론트엔드에는 DB 비밀번호와 외부 AI API 키를 넣지 않는다.
