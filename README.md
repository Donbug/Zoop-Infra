# Zoop-Infra

ZOOP 금융 관계 그래프 서비스의 인프라·클라우드·DevOps 설정을 관리합니다.

ZOOP은 뉴스·공시 속 시장 이슈와 기업, 사용자의 관심·보유 종목 사이의
연결 관계를 근거와 함께 보여주는 서비스입니다.

## 저장소 담당 범위

- 시스템·AWS 아키텍처 설계
- Docker 공통 실행환경 구성
- 서버·네트워크·접근 권한 설정
- CI/CD 및 배포 자동화
- 로그·모니터링·장애 대응
- DB 백업·복원 검증
- 배포·운영 가이드 작성

애플리케이션 코드와 Dockerfile은 각 서비스 저장소에서 관리하고,
이 저장소에서는 서비스 간 연결과 배포·운영 설정을 관리합니다.

## 현재 상태

| 항목 | 상태 |
|---|---|
| 인프라 저장소 | 생성 완료 |
| 시스템 구성도 | 초안 작성, 검토 필요 |
| 서비스 실행정보 | 양식 작성, 담당자 확인 대기 |
| GraphDB | Neo4j 사용 예정, 버전·에디션 미정 |
| 관계형 DB | PostgreSQL·MySQL·MariaDB 중 미정 |
| 백엔드 저장소 | 생성 전 |
| AWS 사용 신청 | 제출 준비 중 |
| 서버 구축·배포 | 진행 전 |

## 작업 규칙

- 변경사항은 작업 브랜치에서 작성하고 PR로 검토합니다.
- 확정되지 않은 기술·자원은 미정으로 표시합니다.
- 실제 구축 상태에 맞춰 문서를 업데이트합니다.
- 실제 환경변수, API 키, 비밀번호, 인증서 개인키,
  DB 데이터와 백업 파일은 커밋하지 않습니다.
